# Spring Security Auth Service 🔐

A Spring Boot-based authentication service built using Spring Security.  
It provides user registration, login, and secure API access using password encryption and authentication mechanisms.

---

## 🚀 Features

- User Registration API
- User Login API
- Spring Security Integration
- Password Encryption using BCrypt
- Custom UserDetailsService
- RESTful Authentication APIs

---

## 🛠️ Tech Stack

- Java 17+
- Spring Boot
- Spring Security
- Spring Data JPA
- Maven
- MySQL (optional if used)
